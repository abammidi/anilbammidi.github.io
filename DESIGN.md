# Portfolio Design Draft

## Who this is for

Hiring managers and recruiters for data engineering, analytics engineering, and data science roles, mainly in financial services and public-sector analytics. They will spend about two minutes on the page.

## What they should know in two minutes

1. I am a data engineer with 15+ years of experience building pipelines and warehouses for payment and risk data.
2. I can turn raw data into decisions: the projects show exploratory analysis, prediction, and recommendation work.
3. Every project links to working code and a README.

## Page structure (single page, vertical scroll)

1. **Hero:** Name, one-line positioning, and links to GitHub and LinkedIn.
2. **About:** Three sentences on background and focus.
3. **Projects (fully populated):** Eight projects with status badges and a link to each folder. Two placeholders for later.
4. **Experience:** Three roles, most recent first.
5. **Education:** Bellevue master's (in progress) and undergraduate degree.
6. **Skills:** Grouped by cloud, data platforms, languages, and methods.
7. **Contact:** GitHub and LinkedIn. Add an email address once I decide to make it public.

## Visual direction

- Plain, high-contrast layout with one accent color, so the project list is the focus.
- Status badges (In progress, Draft, TBD, Not started) on each project so readers see what is finished.
- Project images: one per project, cropped to the same size. Placeholder cards use a neutral image.

## What to highlight first

- The recommendation and prediction projects, since they show modeling skills the employers will test for.
- Payment and risk data experience, since it is the closest match to the financial-services roles I want.
- Links to READMEs that explain the problem, the data, and the result in plain language.
