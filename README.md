# Anil Kumar Bammidi: Data Science Portfolio

Live site: https://abammidi.github.io/anilbammidi.github.io/

This site presents my data engineering and data science work. It links to the project code, notebooks, and READMEs in the [datascience_projects](https://github.com/abammidi/datascience_projects) repository.

## Sections

- **About:** Background and a summary of the portfolio.
- **Projects:** Applied data science projects, each linked to its folder in the repository.
- **Experience:** Roles in data engineering and software development.
- **Education:** Degrees and the Master's in Data Science in progress.
- **Skills:** Tools and methods I use.
- **Contact:** GitHub and LinkedIn.

## Built with

Static HTML, CSS, and JavaScript, with Bootstrap and Font Awesome. The layout started from an open-source template, which is included under [LICENSE.md](LICENSE.md).

## Running locally

Open `index.html` in a browser. No build step is needed.
